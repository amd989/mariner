Installation Vectors

◆ APT

Debian bookworm / trixie and derivatives (Raspberry Pi OS, Armbian)
$ curl -fsSL https://amd989.github.io/mariner/setup.sh | sudo bash
$ sudo apt install mariner3d

The script detects your system codename and selects the matching APT suite. setup-apt.sh is an alias for the same script.

◆ DNF / YUM

Fedora, RHEL, Rocky Linux
$ curl -fsSL https://amd989.github.io/mariner/setup-rpm.sh | sudo bash
$ sudo dnf install mariner3d

◆ Docker

Any platform with Docker
$ docker pull ghcr.io/amd989/mariner:latest
$ docker compose up -d

Packages are built and signed automatically on each release.
