Mariner 2 packages have moved

Mariner now lives at github.com/mariner3d/mariner, and its packages are served from packages.alejandro.md.

Installed from here before?

Nothing to do by hand. Run

sudo apt update && sudo apt full-upgrade

and your machine moves itself over to the new repository.

New install

curl -fsSL https://packages.alejandro.md/setup.sh | sudo sh
sudo apt install mariner3d

Documentation: mariner.readthedocs.io
